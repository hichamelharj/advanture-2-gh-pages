# Advanture 2 - Single Brand Store

This project is a single-brand online store designed for deployment to GitHub Pages.

## Requirements
- **Single-Brand Identity**: No multi-seller or marketplace features.
- **Product Management**: Categories, search, filters, sorting, and stock status.
- **Admin Dashboard**: Store-admin interface for product CRUD and inventory management.
- **Storefront**: Product pages, pricing, delivery info, contact details, and return policies.
- **Checkout**: Simple, mobile-friendly checkout with simulated payment and order submission.
- **Data Persistence**: Local storage for cart, wishlist, inventory, and orders (demo mode).
- **Constraints**: No real payment processing, no customer accounts, no external integrations.

## Tech Stack (Proposed)
- **Framework**: React (via Vite)
- **Styling**: Tailwind CSS
- **Deployment**: GitHub Pages
- **State/Storage**: LocalStorage (for demo persistence)
